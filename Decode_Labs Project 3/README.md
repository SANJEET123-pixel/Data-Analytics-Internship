# DecodeLabs - Data Analytics Project 3

## SQL Data Analysis

This is my third project as part of the DecodeLabs Data Analytics Internship.

In this project, I used SQL to analyze an e-commerce orders dataset and extract useful insights about sales, products, customers and orders.

### Tools Used
- MySQL
- MySQL Workbench
- Excel
- SQL

### SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- COUNT()
- SUM()
- AVG()
- ROUND()

### Key Analysis
- Total orders and revenue
- Average order value
- Product-wise sales
- Payment method analysis
- Order status analysis
- Referral and coupon analysis
- Monthly and yearly sales
- Top customers and orders

### Files
- `Dataset for Data Analytics.xlsx`
- `project3_queries.sql`

### Conclusion

This project helped me improve my SQL skills and understand how SQL can be used to analyze real-world business data.
